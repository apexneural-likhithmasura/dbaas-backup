HOW TO USE THE NEW ENDPOINTS:
================================================================================

1. Start the FastAPI server:
   cd /root/dbas/backend-final/painpont-extractor
   uvicorn main:app --reload --host 0.0.0.0 --port 8000

2. Visit the API documentation:
   http://localhost:8000/docs

3. Test endpoint 1 - Search and Rank:
   curl -X POST http://localhost:8000/reddit/search-and-rank \
     -H "Content-Type: application/json" \
     -d '{"market": "AI tools", "num_results": 30, "top_n": 10}'

4. Test endpoint 2 - Scrape Posts:
   curl -X POST http://localhost:8000/reddit/scrape-posts \
     -H "Content-Type: application/json" \
     -d '{"urls": ["https://reddit.com/r/.../comments/..."], "extract_full_json": true}'
